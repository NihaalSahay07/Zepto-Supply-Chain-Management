# Zepto Supply Chain Management | Power BI Dashboard

A Power BI project exploring grocery retail performance through an interactive dashboard inspired by Zepto. It brings the data into one place so that sales trends, product performance, and customer ratings are easier to understand at a glance.

**Author:** Nihaal Sahay  
**Tools:** Microsoft Power BI · Microsoft Excel · Data Visualization

## Project Overview

Grocery businesses handle a wide range of products, often across categories with different sales patterns and customer preferences. This project focuses on presenting grocery data in a clear, accessible way to support better business decisions.

The repository includes the Power BI report, its Excel data source, and visual assets used in the dashboard.

> **Note:** This is an independent data analytics/portfolio project. It is not an official Zepto dashboard or an affiliated Zepto product.

## What the Project Covers

The dashboard is designed to help explore several useful aspects of grocery retail data:

- **Sales performance:** View sales figures and understand overall business activity.
- **Average sales:** Compare average sales performance across the data represented in the report.
- **Product overview:** Understand the item-related information available in the dataset.
- **Ratings:** Use customer rating information, where available, as another perspective on product performance.
- **Visual reporting:** Bring key information together in Power BI rather than reviewing raw spreadsheet records individually.

These views can be used as a starting point for discussions about product mix, merchandising, and inventory-related decisions. The dashboard is an analytical report, not a live inventory management or order-fulfilment system.

## How to Open the Project

1. Clone the repository or download it as a ZIP file:

   ```bash
   git clone https://github.com/NihaalSahay07/Zepto-Supply-Chain-Management.git
   ```

2. Install **Microsoft Power BI Desktop** if it is not already available on your computer.
3. Open `ZEPTO Dashboard latest.pbix` in Power BI Desktop.
4. Explore the report pages and use any available filters or slicers to investigate the data.
5. If Power BI requests the dataset location, update the Excel data-source path to point to your local copy of `Zepto Grocery Data.xlsx`, then refresh.

## Approach

The project follows a straightforward analytics workflow:

1. **Start with the data:** Use the grocery dataset stored in Excel.
2. **Build the report:** Bring the dataset into Power BI and organize the information for reporting.
3. **Present key indicators:** Use visuals to make important sales and product measures easier to interpret.
4. **Explore the results:** Review the dashboard to identify patterns and questions worth investigating further.

## Why This Project Matters

Good reporting makes business information easier to use. Instead of searching through a spreadsheet for individual values, a dashboard can offer a more immediate view of the overall picture. For a grocery business, that can help teams ask practical questions about sales performance, product assortment, and customer feedback.

This project demonstrates how **Power BI and Excel can be combined to communicate retail data visually**.
